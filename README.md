## 🇺🇸 English
Pokémon Card AI Advisor
Create your deck using the official Pokémon TCG Deck Builder, then simply enter your deck code to receive AI-powered deck analysis and advice.
Import your deck from an official deck code
Get deck-building suggestions
Receive combo and strategy advice
Analyze your deck with regulation and card information
This is an unofficial fan-made tool and is not affiliated with The Pokémon Company.

## Features

- Import decks using an official deck code
- AI deck analysis
- Deck improvement suggestions
- Strategy advice

## How to Use

1. Create a deck using the official Pokémon TCG Deck Builder.
2. Copy the deck code.
3. Paste the code into this app.
4. Receive AI-powered advice.
